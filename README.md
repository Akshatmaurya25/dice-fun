## 🏗️ Tech Stack (For the Devs)

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Blockchain**: Kadena Chainweb EVM Testnet
- **Storage**: Filecoin (via Synapse SDK) - **ALL user uploads stored here**
- **Content Addressing**: IPFS with unique PieceCIDs for every file
- **Identity**: Self Protocol (ZK verification)
- **Wallet**: MetaMask integration
- **Smart Contracts**: Kadena native contracts

### **Filecoin Integration Deep Dive**

- **Every upload gets a PieceCID**: Permanent, content-addressed identifiers
- **Decentralized redundancy**: Files stored across multiple Filecoin storage providers
- **Censorship resistance**: No single entity can delete your content
- **Provable storage**: Cryptographic proofs ensure your files are actually stored
